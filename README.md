# Peach & Avo Ventures

Source for the Peach & Avo Ventures corporate website.

## Website

[peachandavo.co.uk](https://peachandavo.co.uk)

## Local preview

Run the following command from the repository root, then open `http://127.0.0.1:8000` in a browser:

```bash
python3 -m http.server 8000
```

## Publishing

The site is a dependency-free static website. GitHub Pages publishes the `main` branch from the repository root.

## Repository structure

- `index.html` — page content
- `assets/` — styles and website imagery
- `CNAME` — custom-domain configuration for GitHub Pages

Working reference materials are intentionally excluded from this public repository.
